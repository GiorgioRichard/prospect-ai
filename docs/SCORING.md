# Score e Radar
Pontuação por serviço, não probabilidade de compra. Versão inicial proposta: necessidade técnica 30, aderência ao serviço 25, sinais comerciais observáveis 20, capacidade comercial estimada com evidência 15, qualidade/atualidade 10. Cada fator normalizado 0–1; soma ponderada arredondada. Dados desconhecidos não pontuam e reduzem cobertura; nunca inventar orçamento. Confiança separada: cobertura ponderada de evidências válidas, com qualidade calibrada no piloto. Classes A >=80, B >=60, C abaixo; confiança baixa exige revisão antes de priorizar. Exibir fatores, evidências e versão. Excluir contatos suprimidos. Desempate por confiança, atualidade e ID. Recalcular após revisão/expiração; manter snapshots.
Exemplo: fatores 1, .8, .5, 0, .8 => 68 pontos. Interesse real só após interação registrada. Feedback relevante/não relevante não altera pesos automaticamente; calibrar com conjunto revisado e versionar mudanças.

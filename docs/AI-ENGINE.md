# Inteligência artificial
Interface `analyze(task, evidenceIds, schemaVersion, budget)` com adaptadores OpenAI Responses e Anthropic. Codex/Claude Code são ferramentas de desenvolvimento, não dependências de runtime. Tarefas P1: avaliação visual, UX, interpretação de conteúdo, recomendações e revisão de mensagens. Entrada mínima, conteúdo web tratado como não confiável, sem instruções executáveis ou ferramentas privilegiadas. Saída JSON validada por Zod, referências a IDs de evidência, hipóteses separadas de fatos. Revisão humana antes de uso comercial. Registrar modelo, versão do prompt, tokens, custo e latência; limites por tenant, timeout, retries limitados, fallback determinístico. Nunca enviar segredos ou dados pessoais desnecessários. Avaliar retenção e contratos dos provedores antes de produção.
